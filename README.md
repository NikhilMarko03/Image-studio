# Image-studio
web-app code file for an app which contains 4 features namely : image resize / background remover / image to pdf / switch format.
Download the zip file of this code.
Extract it at your desired location.
Make sure to download android studio and nodejs beforehand.
Open the extracted location and run command prompt there by right clicking on the mouse.
In cmd, write these commands:-
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
this last command will open the android studio, make sure to setup the android studio.
in the latest version you might have to install the emulator first. So just google it. 🤣
Or if you don't wanna do that then just let the process complete and hover the cursor over the three lines at the top left side there find build and go to generate apk option click it. Then the apk file will be generated.
At the bottom left corner a notification will arrive it will say [locate] and [analyze].
Click locate and you will be directed to apk file location copy it into your mobile device.
